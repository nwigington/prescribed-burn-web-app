Map workflow

Burn Map

  1. Find a location. Pan and zoom the map or use the locate control to move to your current position.
  2. Review context. Change basemaps and turn operational or sensitive-area layers on and off.
  3. Draw or identify. Use the Map tools drawer to create a burn unit or inspect an existing unit.
  4. Save and plan. Enter unit details, preferred conditions, forecast data, smoke screening, and burn events.
Operational Limitation

Map graphics and model outputs support planning only. Verify boundaries, permits, smoke-management requirements, and field conditions through approved agency processes.

    Help and Accessibility

    Using the Prescribed Fire Operations Hub

    Core Workflow

    1. Locate the proposed burn area.
    2. Draw or select a burn unit.
    3. Enter unit details and preferred conditions.
    4. Review forecast scores and smoke-sensitive areas.
    5. Request an official NWS Spot Forecast.
    6. Document planned and completed burn events.

    Keyboard and Non-Map Access

    Use Tab and Shift+Tab to move through controls. Arrow keys move among application tabs. Burn records, forecasts, and events are available in structured tables and text panels.

    Reference Guide

    The Tall Timbers guide supplied for this prototype is included as design reference material. California laws, agency policy, permit conditions, and local air-district requirements control State Parks operations.
